# Linker flags for packages linking against VTK

Returns the linker flags (`-L` paths and `-l` library names) required to
link C++ code against VTK. Intended to be called from a downstream
package's `configure` or `configure.win` script:

## Usage

``` r
LdFlags()
```

## Value

A single character string of linker flags, written to stdout (so that it
can be captured by shell command substitution in `configure`) and
returned invisibly.

## Details

    VTK_LIBS="$("${R_HOME}/bin/Rscript" --vanilla -e "rvtk::LdFlags()")"

On Windows the full set of VTK linker flags can exceed the 8
191-character command-line limit. Prefer
[`LdFlagsFile()`](https://astamm.github.io/rvtk/reference/LdFlagsFile.md)
on Windows to write the flags to a response file instead.
